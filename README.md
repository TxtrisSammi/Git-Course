# Task Tracker/Git Class

## About

The Task Tracker tracks the tasks that you have to do. Everything is done through code and there is no UI, because UI is for losers.

### Features

- Stores the list
- Prints the list
- Displays tasks neatly

### Methods

|  Method  |     Args                           |      Output                                    |
|----------| -------------                      | -----------------                              |
|PrintList | String[] list                      | void, prints list                              |
|AddToList | String[] list, String itemToAppend | String[], returns new array with item appended |
| main     | String[] args                      | void, runs the main code block                 |
